# Power BI Sales Dashboard

## About the Project
This project is an interactive dashboard developed using Microsoft Power BI.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objectives
- Analyze total sales.
- Understand profit performance.
- Identify top-performing products.
- Analyze monthly sales trends.
